# Your hero characters go here

Drop transparent **PNG / WebP / AVIF** cut-outs (about 1000–1400 px, background removed) in this folder.
The file name must match a hero object id from `src/data/hero-objects.js`:

`orb  bloom  drop  star  pill  cloud  cube  cup  wave`

Example: `src/assets/hero/orb.webp` replaces the pink ball. Objects without a file keep the placeholder.
You can rename ids, labels, hover colours and positions in `hero-objects.js` to match your own characters.
